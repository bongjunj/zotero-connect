# zotero-connect

An Emacs interface for searching a running Zotero desktop library and exporting BibTeX through Zotero's local API.

## Requirements

- Emacs 29.1 or later.
- A running Zotero desktop app with **Settings → Advanced → Allow other applications on this computer to communicate with Zotero** enabled.
- macOS for opening a selected item in Zotero. Other features use standard Emacs libraries.

The package reads the local Zotero API; it does not start Zotero sync or upload data. Local API read access is available to other processes on the same computer. Keep the API bound to localhost.

## Installation

Clone this repository and add its directory to Emacs's load path:

```elisp
(add-to-list 'load-path "/path/to/zotero-connect")
(require 'zotero-connect)
```

Optional key bindings:

```elisp
(keymap-global-set "C-c r s" #'zotero-connect-search)
(keymap-global-set "C-c r b" #'zotero-connect-insert-bibtex)
(keymap-global-set "C-c r w" #'zotero-connect-copy-bibtex)
(keymap-global-set "C-c r c" #'zotero-connect-insert-citation)
(keymap-global-set "C-c r e" #'zotero-connect-export-library)
```

## Commands

- `zotero-connect-search`: choose a personal or group library, search its items and select one in Zotero.
- `zotero-connect-insert-bibtex`: choose an item and insert its BibTeX at point.
- `zotero-connect-copy-bibtex`: choose an item and copy its BibTeX to the kill ring.
- `zotero-connect-insert-citation`: select an existing `.bib` file and insert a `\cite{key}` for a selected entry. It also reads unsaved changes in a visiting bibliography buffer. It does not modify the bibliography and does not require Zotero to be running.
- `zotero-connect-export-library`: choose a `.bib` file, library and either the whole library or a collection. The selected collection includes directly assigned items, not its subcollections. The export replaces the bibliography **buffer**, which must be reviewed and saved manually; unsaved changes in that buffer are protected. Existing manually maintained entries will be replaced on save.

BibTeX keys are generated by Zotero's export. Re-exporting can alter keys as library metadata changes, so review changes before saving.
